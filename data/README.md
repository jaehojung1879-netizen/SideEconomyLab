# Data

Do not ingest data merely because it exists.

## Likely source classes
- Seoul Open Data
- Seoul Commercial District Analysis
- national public-data portals
- map / geocoding sources
- supplier quotes
- competitor prices
- field counts
- device telemetry
- payment / usage records
- maintenance logs

## Rule
Start with downloadable CSV / public files during exploration.
Add APIs only after a dataset proves useful enough to refresh repeatedly.

Never commit credentials or API keys.
