이번 실자료는 비교 조건을 충족하지 못해 **시장 변화 신호 0건**입니다. 첫 화면은 이 사실과 다음 확인을 설명하면서 기존 지역 연구로 연결합니다. 관측 자료를 실제 시장 공백·수익·사업 승인으로 표현하지 않습니다.

## 신호와 미해결 무결성

계산기는 전년 동분기 소비/점포 증가율과 최근 3분기 개폐업 방향을 결정적으로 도출합니다. 실제값·기준·기간·출처·완결성·대안 설명·다음 행동을 남깁니다. 단일 수익 점수는 없습니다. 활동 변화는 비활성이고 연구 가설은 생성하지 않았습니다.

공식 지리 개정 공지는 확인했지만 분기별 경계 버전·CRS·기존 1,650 상권과의 대응은 검증하지 못했습니다. 비교 활성화에는 지리 버전·경계 버전·CRS·공식 근거와 완결된 동일 기간/업종 데이터가 필요합니다. 현재 새 통계 영역은 별도 지리 도메인입니다. 이름·중심점 조인은 하지 않고 지도 레이어와 추세선을 비활성화했습니다. 지도를 클릭하면 기존 지역 맥락이 갱신되고 새 관측 선택은 지도 위치를 바꾸지 않습니다.

250m 인구·이동·교통·행사·주거·추가 시설은 이번 신규 통합에서 보류했습니다. 인증 수집이 차단된 1차 출처는 최종 상태에 없습니다. 미통합 자료의 메타데이터 접근을 실제 관측 수집으로 표현하지 않습니다. 기존 `DATA_GO`·`R_ONE` 자료는 보존했고 새 호출은 하지 않았습니다. 공식 HTTP :8088 제공 방식의 암호화 전송 지원 확인은 남아 있습니다.

## 검증과 화면 증거

- Python 67개: 기존 50개 + 신규 17개. 스키마·인증 실패·페이지 누락·중복·기간·지리·단위·신선도·결정성·실패 보존·출처·실자료 재현을 검증했습니다.
- 기존 의사결정 모델, 경제 계산/개인 저장 13개 회귀 그룹, 부동산 맥락, GIS 의존성·판단 증거·후보 검증 묶음 검사 통과.
- 새 탐색 및 기존 GIS·사업 구성·의사결정·검증 현황 브라우저 검사 통과. 1440px·1024px·390px에서 수평 넘침 없이 필터, 상세, 지도 맥락, 후보 유지, 뒤로 이동, 사업성 연결, 모바일 패널과 복귀 버튼을 검사했습니다.
- 네트워크 실패·수집 실패·오래된 자료·상세 해시 불일치·적격 신호 없음·지도 대응 없음은 명확한 안내로 처리했습니다. 합성 호환 신호는 브라우저 네트워크 테스트에만 사용했으며 실자료에 저장하지 않았습니다.
- 로컬 기존 GIS의 직접 CDN 실행은 이 환경의 외부 접근 때문에 실패했습니다. 고정 버전 CDN 패키지와 요청한 실제 OSM 타일을 검증된 TLS/세션 프록시로 전달해 동일한 GIS 검사를 통과했습니다. TLS 검증을 해제하지 않았습니다. 실제 Kakao 계정·도메인 허용은 미확인이고 SDK 계약/거부 대체 동작만 테스트했습니다.
- [보존 검사](radar-preservation-v1.json): 기존 데이터·지도 설정·어댑터·경제/판단 모델·현장 기록의 바이트 일치와 후보 포트폴리오의 판단 내용 일치를 확인했습니다. UI와 GIS 호환 경로의 해시만 의도적으로 재결합했습니다. GitHub PR 검사에서 동일 검증을 다시 실행합니다.

## 성능과 실용성 평가

새 첫 화면 요약은 111,773바이트이며 상세 186개는 합계 883,498바이트, 개별 최대 4,828바이트입니다. 선택 시 한 파일만 불러오고 지도/후보 조작은 원천 API나 무관한 상세 다운로드를 일으키지 않습니다. 초기 지도는 기존 상위 12곳만 표시합니다. 약 13.79MB의 기존 판단 증거는 사업성 검토 진입 시 지연 로딩합니다.

로컬 브라우저의 초기 공개 JSON 응답 합계는 약 3.95MB였습니다. 기존 경쟁·맥락 파일과 타일/CDN 의존성은 남아 있습니다. [요청별 측정](screenshots/opportunity-radar-v1/initial-load.json)은 로컬 서버·고정 CDN 패키지를 사용한 결과이며 배포 환경의 속도 보장은 아닙니다. 스크린샷은 연구 기록으로만 보관하며 앱이 내려받지 않습니다.

기술적으로 실제 수집 → 불변 보존 → 엄격한 비교 게이트 → 작은 요약/상세 → 기존 검토 연결이 동작합니다. 사용성 측면에서는 첫 화면과 다음 검증이 명확해졌지만, **실제 시장 변화의 발견·해석은 지리 근거 확보 전까지 완성됐다고 주장할 수 없습니다.** 기존 연구와 개별 관측을 조사하는 흐름은 사용할 수 있습니다.

## 병합 전 확인과 v2

PR 전체 검사 성공을 확인하고, 배포 도메인의 실제 Kakao 허용·키 설정과 실사용자 10초 이해 여부를 확인하세요. 기존 개인 저장본 백업/복원을 해당 기기에서 점검하고, source domain의 두 지역 범위·기간·라이선스 표시 및 실제 수집 절차를 검토하세요. 비교 게이트가 닫힌 상태에서는 지리 대응 없이도 코드 검토가 가능하지만 검증 없이 신호·추세·새 지도 레이어를 켜면 안 됩니다.

v2는 데이터 종류를 늘리기 전에 공식 분기별 경계/대응표와 업종 정의를 확보해 작은 범위의 비교를 여는 것이 우선입니다. 그 뒤 실제 변화 하나에서 고객 문제 인터뷰·현장 점포 확인·사이트 견적까지 이어지는 최소 검증을 수행하세요. 예측 모델·자동 승인·구매·새 인프라는 보류합니다.
