# Field Interview Template

## Metadata
- date:
- interview type: host / user / supplier / operator / other
- segment:
- location:
- candidate ID:

## Current behavior
1. What do you do today?
2. How often does the problem occur?
3. What do you currently pay?
4. What is most inconvenient?
5. When did it last happen?

## Behavior, not compliments
- Have you paid for an alternative in the last 90 days?
- What happened the last time the need arose?
- Why did you choose the current alternative?
- What would make you switch?

## Transaction test
- Would you run a trial?
- What conditions would be required?
- Would you pay / share revenue / place a deposit?
- Who approves?

## Operational constraints
- acceptable installation / access
- electricity / water / network
- hours
- maintenance
- liability / complaints
- settlement terms

## Evidence strength
- stated interest only
- contact shared
- follow-up scheduled
- trial agreed
- written intent
- deposit / payment
