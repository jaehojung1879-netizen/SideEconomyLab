# SideEconomyLab

Research and experiment repository for building an independent side economy that can coexist with a demanding full-time job.

The project is intentionally broader than micro-assets or unmanned stores. It compares physical, hybrid and asset-light business models under one framework and adds code only when data or repeatability justifies it.

## Objective

Identify, validate and operate at least one side business that:
- can coexist with a demanding full-time job;
- requires limited weekday interruption;
- can start with controlled seed capital;
- can generate repeatable cash flow;
- can reinvest its own earnings into expansion;
- uses AI primarily to compress owner labor and improve decisions;
- is not easily substitutable by a general-purpose AI assistant;
- can eventually create proprietary operating data.

## Research scope

Potential archetypes include hosted or standalone micro-assets, rental assets, small-format spaces, route businesses, unattended retail, B2B recurring equipment or procurement, niche commerce, recommerce, service operations, small-scale production, physical-digital hybrids and compact experiences.

The repository does **not** assume that any one archetype is the answer.
